# 数贸会线索与合规交易

本项目保存数贸会线索与合规交易所需的领域上下文、校验契约与跨境数字订单
争议归档分流的可运行领域模型，便于服务端功能围绕真实业务参与方展开。
当前版本只提供资料读取、结构校验、争议流转逻辑和命令行摘要，数据均为演示用虚构内容。

## 参与方

采购方、参展企业、会务交易团队、材料审核人员

争议场景扩展参与方：采购方智能助手（自动下单代理）、电子签名平台、
跨境结算机构、国际商事调解团队、平台运营者。

## 事实资料

- 第五届全球数字贸易博览会在杭州举行并设置主题馆和产业展区
- 展会强调可触达、可互动和可交易
- 报道提出智能体下单、电子签名、跨境支付和争议解决的规则问题

## 争议归档与分流服务（`disputes`）

`src/trade_expo_collaboration/disputes.py` 实现按案件发生时有效规则版本
（快照 `RuleSet 2026.09`）归档的可复核争议流程：

- **收件去重**：订单事件立案；事件按业务主键生成指纹，相同事件重复提交返回原案件；
  授权等材料早于订单到达时按订单号暂存，立案后补登记。
- **自动分流与冻结**：核心材料（订单、代理授权、签名、出境同意、支付、管辖）齐全后，
  小额争议进速调通道；签名与支付金额不符、支付早于签署且无预授权、代理范围冲突等
  矛盾会冻结自动分流并转人工核证队列。
- **角色权限**：调解员只能查看获授权的原件（同意须显式允许调解阅卷）；
  平台运营者可补充交易事实（`fact`），但无权提交或改写当事人陈述；
  当事人同一日对同一事项的在先陈述不可覆盖，只能追加新陈述。
- **跨境数据**：转交逐份核对数据类别、接收方与同意有效期；缺同意整体拒绝；
  每次查看与转交都记录访问人、原因、接收方和准许/拒绝结果。
- **补充协议**：只能改变尚未裁定的事项，且不得替换已在裁定中使用的证据；
  引入新的未裁定事项时案件恢复审理，既往裁定不动。
- **程序推进**：调解、诉讼、撤回分别设置响应/应诉/归档期限、通知和费用状态，
  并可按日推进（期限届满提醒、费用到期与缴费）；材料冻结不阻止当事人选择程序。
- **裁定溯源与恢复**：每项裁定记录触发交易的代理行为、规则版本和完整证据链；
  案件可导出快照并按同一规则版本恢复，恢复后继续推进并可重复验重。

争议包含：规则快照、事件原件（含指纹与不可变标记）、冻结原因、补充协议与
已裁定事项索引、期限/通知/费用、访问与转交审计日志、裁定溯源索引。

### 命令行

```bash
# 摘要
python3 -m src.trade_expo_collaboration.disputes fixtures/dispute_case.json

# 生成可复核争议包 JSON
python3 -m src.trade_expo_collaboration.disputes fixtures/dispute_case.json /tmp/争议包.json

# 事件信封契约
# contracts/dispute.schema.json
```

演示案件 `fixtures/dispute_case.json`：采购方智能助手在授权期内自动下单
（CNY 3,280，小额）、电子签名平台当日签署、新加坡跨境结算机构次日分两笔结算、
合同约定先调解后诉讼、采购方授权调解阅卷并向新加坡接收方出境数据。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：事件校验与指纹去重、乱序暂存、签名/支付矛盾冻结、多笔结算合并比对、
授权阅卷与越权留痕、运营者补充事实边界、陈述防改写、出境同意校验、
补充协议对已裁定事项与已用证据的限制、调解/诉讼/撤回的期限通知费用推进、
裁定证据链溯源、快照恢复与规则版本不符拒绝恢复。
